# Documentation

This folder contains supporting documentation for the **Moontuner Chaperone** repository and, specifically, the `stitch_lunar_chaperone/` project currently stored inside it.

## Documents

- [`overview.md`](./overview.md) — what the project is and what it appears to contain
- [`architecture.md`](./architecture.md) — how the repository is structured and how the assets relate to each other
- [`content-model.md`](./content-model.md) — the workbook system, data files, and content patterns
- [`navigation.md`](./navigation.md) — intended user flow and prototype navigation logic
- [`design-system.md`](./design-system.md) — the visual language, typography, layout, and interface conventions

## Recommended reading order

If you are new to the repo, read in this order:

1. `overview.md`
2. `architecture.md`
3. `content-model.md`
4. `navigation.md`
5. `design-system.md`

## Intended audience

These docs are useful for:

- the repository owner
- collaborators refining the archive
- designers translating the prototype into a more complete product
- developers converting the static HTML exports into a maintainable site or app
- writers/editors shaping the workbook system into a publishable format

## Notes

At the time these docs were written, the repository appears to be primarily a **static prototype/archive export** rather than a fully wired software application with a build pipeline.

That means the documentation focuses on:

- understanding the current structure
- identifying the source materials
- clarifying the conceptual model
- making future implementation easier
