# Project Overview

## Summary

`moontuner-chaperone` currently appears to house a static prototype/archive for the **Lunar Chaperone** system: a 26-workbook body-based lunar guidance experience expressed through editorial HTML screens, workbook modules, CSV metadata, and archive-style navigation concepts.

The core project folder is:

```text
stitch_lunar_chaperone/
```

Within that folder, the repository combines:

- landing and index pages
- workbook modules
- dashboards
- archive/index concepts
- CSV content maps
- design and navigation specification documents
- exported prototype screens

## What Lunar Chaperone appears to be

Based on the repository contents, **Lunar Chaperone** is a structured lunar self-guidance or reflective workbook system organized around recurring sign-to-sign energetic transitions.

The system includes:

- **24 core workbooks** covering cyclical lunar arcs
- **2 eclipse portal workbooks** for special threshold periods
- repeated emphasis on:
  - somatic inquiry
  - ritual structure
  - archetypal transitions
  - archival/editorial design
  - reflective and research-oriented prompts

The tone of the project blends:

- mysticism
- embodiment
- ritual practice
- literary archive aesthetics
- structured progression

## What this repository is not, yet

From the files currently visible, this repository does **not** obviously include:

- an application framework
- package management files
- a test suite
- a build pipeline
- reusable front-end components in a formal codebase structure
- server-side logic

Instead, it looks more like a **design-exported static site/prototype** with content and concept assets organized into folders.
