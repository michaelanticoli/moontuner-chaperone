# Lunar Chaperone: Project Export & Organization Map ## 1. Project Overview **Title:** Lunar Chaperone: The Canonical Archive **Concept:** A consecutive, 26-workbook sequential series guiding users through 14-day lunar transitions. **Visual Identity:** "The Canonical Archive" — Academic minimalism, paper-like textures (#F4F1EA), and high-contrast archival typography. ## 2. Global Export Instructions To export this project as a complete unit for development or further design: 1. **Export to Figma:** Use the **Export to Figma** button in the top toolbar to move all generated screens into a collaborative design environment. 2. **Export Code:** Click the ** View Code** button on any screen to access and copy the underlying HTML/Tailwind CSS for each module. 3. **Project Assets:** All uploaded CSVs and data files are stored in the project's DataStore for reference. ## 3.
